# תוכנית עבודה: מאגר היתרי עיסקא (נשמר כדי לבנות ממנו את הדשבורד החדש)

## כללי עבודה שסוכמו
- הקובע הוא הפוסט המקורי באתר הישן (רשימת כללי / פרטי), בתנאי שלא היו שאלות, או שאושר ב"מסמכים לבדיקה".
- אישור בדשבורד בלי בחירות אינו משנה כלום; רק מסמן שהרישום המקורי נבדק.
- לכל חברה: הת"ע פרטי אחד, הת"ע כללי אחד, ו"אחר" בכמה שרוצים (עם כותרת ופירוט חובה). מסמך אינו "אחר" וגם פרטי / כללי.
- אין להכניס שינויים בלי אישור המשתמש. ה-SQL ב-D1 מריץ המשתמש בעצמו.

## שלב 1: רישומים כפולים / תת-רישום לחברה
- בוצע: אותו ח.פ. בכמה שורות = שורה ראשית + תת-שורות ("↳"), בטבלת הניהול ובטבלת התצוגה.
- מסלול הלכה: שורה נפרדת רק במגדל (520004896) ומיטב (512065202). 40 חברות נוספות יש להן רק הערה "צריך מסלול כשר" (אין כפילות).
- כפילות קופת חולים מאוחדת (5849/99) נמחקה.
- פתוח: חברות עם הת"ע מיוחד **לאג"ח בלבד** (למשל אביעד פיקדונות, אביעד ריביות, אלומה קרן תשתיות, אמפא, בי קומיוניקיישנס,
  בתי זקוק לנפט, כרמל אולפינים, לוינסקי עופר, מיטב בית השקעות, נאוויטס פטרוליום, עלמא יסודות, פוקס-ויזל). לבדוק בבסיס הנתונים החי
  (agch_approved = 'בחירת אג"ח מסוימים' / הערות "לאג"ח בלבד", וטבלת approved_bonds) ולטפל כמו מסלול הלכה (שורה ראשית + תת-שורה). לא הוחלט עדיין איך.

## שלב 2: סקירה מלאה של כל מסמך
- `build_text_index.py`: טקסט מכל העמודים (שכבת טקסט + OCR), כל מספרי התאגיד, שמות, מסד חיפוש (`search_text.py`).
- `ink_ocr.py`: חותמות (גם עגולות), עט צבעוני וכתב יד בתוך עמוד מודפס, בעיקר למספרי ח.פ. (וגם שמות). כל תוצאה עם תמונה לאימות ידני.
- הבא: ייבוא ל-D1 (טקסט, ח.פ., שמות, תוצאות הכתב יד / חותמות) לחיפוש מהאתר ולהצעות שיוך בדשבורד.

## שלב 3: חיפוש חברה באתר + דשבורד חדש
- חיפוש חברה (fuzzy כמו ב-revach), חברות במאגר וחברות שאינן במאגר, כרטיסיות; בחירה אחת של רשימת חברות ואג"ח מאושרים; ביטול תפריטי הפרטי / כללי המיותרים ב-WordPress.
- דשבורד מחדש, שלוש לשוניות:
  א) חברות שחסרים להן שטרות: לפי חברה; כל חברה ברשימות פרטי / כללי צריכה שטר משויך. אפשרות להציג גם חברות עם מסמכים נוספים (שאינם הראשיים).
  ב) שטרות שמחכים לשיוך: כל שטר שאינו משויך; אחרי מיפוי ח.פ. ושמות מהטקסט, להוסיף כל הצעה מתאימה.
  ג) חברות לא רשומות: שטר במאגר, החברה לא ברשימה. ברירת מחדל בלי מחוקות / מוזגו; חיפוש ברשימת כל החברות / עמותות לפי שם / ח.פ.
